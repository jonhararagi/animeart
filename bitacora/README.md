# Bitácora de sesiones

## Punto de entrada

La próxima sesión debe leer primero:

1. `bitacora/ACTUAL.md`
2. la última bitácora fechada;
3. `problema de huesos/REGISTRO.md`;
4. `docs/TRABAJO-MAPA.md`;
5. `docs/MODO-DE-TRABAJO.md`.

## Regla de corte

Cada bloque de trabajo dura como máximo 5 minutos operativos. Al llegar al límite se guarda el estado antes de continuar.

## Archivos

- `ACTUAL.md`: estado de continuación inmediato.
- `YYYY-MM-DD-sesion-NN.md`: historial de sesiones.

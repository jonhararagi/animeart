# Problema de huesos

Registro permanente de problemas técnicos, arquitectónicos, de integración, pruebas y continuidad.

## Qué entra aquí

- fallos de CI;
- errores de compilación;
- regresiones;
- contradicciones entre Android y Web;
- duplicación de arquitectura;
- problemas de persistencia;
- errores de coordenadas/transformaciones;
- problemas de pruebas;
- bloqueos que impidan continuar;
- decisiones que requieran seguimiento.

## Regla

**Cada problema detectado se registra. Cada problema solucionado conserva su registro y añade evidencia de la solución.**

No se eliminan problemas resueltos.

## Formato

Usar el formato de `REGISTRO.md` y, cuando el caso sea complejo, crear un archivo individual:

`PB-XXX-nombre-corto.md`

Estados permitidos:

- ABIERTO
- EN INVESTIGACIÓN
- RESUELTO
- BLOQUEADO
